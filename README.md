# Web Resume

## Author

Chloe Washington

## Project Description

This project is a web-based version of my current professional resume.

The website was created using HTML and CSS and is designed to provide
a professional and accessible version of my resume that can be viewed
online.

A PDF version of the resume is also included.

## Technologies Used

- HTML
- CSS
- GitHub
- Microsoft Azure

## Files

- `index.html` - Main HTML webpage
- `index.css` - External CSS stylesheet
- `resume.pdf` - PDF version of the resume
- `README.md` - Project documentation
- `LICENSE` - Project license

## How to Run Locally

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` using Live Server.
4. View the website in a web browser.

## PDF Resume

The PDF version of the resume can be accessed through the
"PDF Resume" button on the website.

## Deployment

The website is hosted using Microsoft Azure Static Web Apps.

The master copy of the project is maintained using GitHub.
